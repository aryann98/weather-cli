# 🌦️ Weather CLI

A simple command-line weather application built with Python and the `requests` library.

The application takes a city name, finds its geographical coordinates using the Open-Meteo Geocoding API, and then fetches the current weather conditions.

## ✨ Features

- 🌍 Search weather by city name
- 🌡️ Current temperature
- 💧 Humidity
- 🌬️ Wind speed
- 🕒 Current weather time
- 🎨 Colored terminal output
- ⚠️ Handles invalid cities and request errors
- ⏱️ Request timeout handling

## 🛠️ Technologies Used

- Python
- Requests
- Colorama
- Open-Meteo API
- Git & GitHub
